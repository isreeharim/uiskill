## 1. When to Use This Skill

Activate this skill when:
- **Selecting a UI Stack**: Deciding between shadcn/ui, MUI, Mantine, Ant Design, HeroUI, etc.
- **Designing Components**: Implementing complex widgets (Data Tables, Command Palettes, Modals, Forms, Bento Grids, Metric Cards).
- **Styling & Theming**: Setting up design tokens, CSS variables, dark mode toggles, or OKLCH palettes.
- **Migrating Between Libraries**: Converting an MUI component to shadcn/ui or vice-versa.
- **Crafting SaaS Interfaces**: Building B2B dashboards, analytics cards, or marketing hero blocks.
- **Adding Micro-Interactions**: Integrating modern motion effects (21st.dev, Framer Motion, Tailwind Variants).
- **Ensuring Accessibility & RSC Compliance**: Fixing focus traps, hydration errors, or `"use client"` boundary issues.

## 4. The 12 Libraries: Architectural Signatures

### 1. shadcn/ui (`https://ui.shadcn.com`)
- **Key Concept**: Not a component library in `node_modules`. Components live directly in your `src/components/ui`.
- **Core Primitives**: Radix UI (accessible state) + Tailwind CSS (styling) + `clsx` & `tailwind-merge` (`cn()` helper).
- **CLI**: `npx shadcn@latest add button dialog table`
- **Config**: `components.json` manages aliases, styles, and CSS variables.

### 2. Untitled UI React (`https://untitledui.com/react`)
- **Key Concept**: Industry-standard enterprise SaaS UI design system with 10,000+ variants in Figma and matching React/Tailwind implementations.
- **Signature Strength**: High-converting metric summary cards, breadcrumbs, faceted search filters, audit logs, team management tables.
- **Styling**: Tailwind CSS classes configured with Untitled UI typography and shadow tokens.

### 3. MUI Material UI (`https://mui.com/material-ui/all-components`)
- **Key Concept**: Google Material Design (M2/M3) implemented with exhaustive component coverage.
- **MUI X**: Industry-leading enterprise data tools: `<DataGridPro />`, `<DateRangePicker />`, `<TreeView />`.
- **Theming**: `createTheme()` + `<ThemeProvider theme={theme}>` with `sx={{ ... }}` prop.

### 4. Reshaped (`https://reshaped.so`)
- **Key Concept**: Token-first, Figma-synchronized design system using native `--rs-` CSS variables.
- **Zero Runtime Overhead**: No CSS-in-JS engine required. Tokens compile into standard CSS custom properties.
- **Polymorphism**: Uses clean `as="a"` or `as="button"` polymorphic props.
- **Wrapper**: `<Reshaped theme="slate" defaultColorMode="dark">`

### 5. AlignUI (`https://www.alignui.com`)
- **Key Concept**: Clean, modern SaaS UI kit engineered specifically for Tailwind CSS and React with Radix primitives.
- **CLI**: `npx @alignui/cli` to inject tokens, OKLCH palettes, and Remix Icon bindings.
- **Architecture**: Compound components (`<Button.Root>`, `<Button.Icon>`).

### 6. Base UI (`https://base-ui.com`)
- **Key Concept**: Next-generation unstyled, headless React components by the MUI core team (collaborating with Radix and Floating UI authors).
- **Advantage**: 100% accessible logic without a single bundled line of CSS. Compatible with Tailwind, CSS Modules, or vanilla CSS.
- **Package**: `@base-ui/react`

### 7. Tailark (`https://tailark.com`)
- **Key Concept**: Pre-built SaaS marketing sections and page blocks built on top of shadcn/ui and Tailwind.
- **Aesthetic Kits**: *Dusk* (dark-mode sleek), *Veil* (minimalist clean light), *Mist* (Notion-style).
- **Use Case**: Drop-in hero sections, pricing matrices, testimonial clouds, and CTA banners.

### 8. HeroUI (`https://heroui.com`)
- **Key Concept**: Formerly NextUI. High-performance, animated React library built with Tailwind Variants (`tv()`) and React Aria.
- **Visual Style**: Apple-grade smooth spring physics, subtle borders, frosted glassmorphism, and instant ripple feedback.
- **CLI / Package**: `@heroui/react`

### 9. Mantine UI (`https://ui.mantine.dev` & `https://mantine.dev`)
- **Key Concept**: The complete batteries-included React toolset: 100+ components, 50+ hooks (`@mantine/hooks`), and standalone form validation (`@mantine/form`).
- **Styling**: Modern CSS Modules with style props and zero runtime CSS overhead (Mantine v7+).
- **Specialties**: Notification center (`@mantine/notifications`), command spotlight (`@mantine/spotlight`), modals manager.

### 10. DaisyUI (`https://daisyui.com`)
- **Key Concept**: Pure CSS Tailwind plugin adding semantic component classnames (`btn`, `card`, `badge`, `modal`).
- **Advantage**: Zero JavaScript footprint for base elements. Compatible with React, Vue, Svelte, or server templates.
- **Themes**: 30+ built-in themes toggled via `<html data-theme="dark">`.

### 11. Ant Design (`https://ant.design`)
- **Key Concept**: Enterprise-class UI design language and component suite for dense backoffices and international enterprise tools.
- **Theming**: Antd v5 token algorithms (`theme.defaultAlgorithm`, `theme.darkAlgorithm`) wrapped in `<ConfigProvider>`.
- **Specialties**: Complex cascading filters, tree tables, multi-step financial forms.

### 12. 21st.dev (`https://21st.dev`)
- **Key Concept**: "The npm for design engineers." Community registry of modern micro-interactions, canvas effects, bento grids, and animated buttons.
- **Tech Stack**: Tailwind CSS + Framer Motion + Lucide. Integrates with Cursor/Claude Code via MCP and CLI (`npx 21st`).

### 13. React Bits (`https://reactbits.dev` & `https://github.com/DavidHDev/react-bits`)
- **Key Concept**: Curated open-source collection of 200+ animated React components by David Haz.
- **Specialties**: Statement typography (`ShinyText`, `TrueFocus`, `SplitText`), 3D cards (`TiltedCard`, `StarBorder`), cursor physics (`Magnet`), and interactive canvas backgrounds (`Aurora`, `Squares`, `Particles`).
- **Tech Stack**: React + Tailwind CSS + Framer Motion. 100% MIT, copy-paste ownership.

## 5. Universal Component Architecture

When generating or refactoring UI components in any codebase, enforce this 5-layer standard:

```
┌────────────────────────────────────────────────────────┐
│  1. CONSUMER LAYER (Page / Feature Component)          │
│     - Handles business logic, query hooks, state       │
├────────────────────────────────────────────────────────┤
│  2. COMPONENT COMPOSITION LAYER                        │
│     - Compound subcomponents (Root, Trigger, Content)   │
├────────────────────────────────────────────────────────┤
│  3. ACCESSIBILITY & STATE PRIMITIVE LAYER              │
│     - Headless hooks / primitives (Radix, Base, Aria)  │
├────────────────────────────────────────────────────────┤
│  4. STYLING VARIANT LAYER                              │
│     - CVA (class-variance-authority) or Tailwind Var.  │
├────────────────────────────────────────────────────────┤
│  5. TOKEN & THEME LAYER                                │
│     - CSS Custom Properties (OKLCH, HSL, RGB)          │
└────────────────────────────────────────────────────────┘
```

## 6. Rosetta Stone: Canonical Button Implementation

### A. shadcn/ui (CVA + Radix Slot)
```tsx
import * as React from "react"
import { Slot } from "@radix-ui/react-slot"
import { cva, type VariantProps } from "class-variance-authority"
import { cn } from "@/lib/utils"

const buttonVariants = cva(
  "inline-flex items-center justify-center gap-2 whitespace-nowrap rounded-md text-sm font-medium transition-colors focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-ring disabled:pointer-events-none disabled:opacity-50",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground shadow hover:bg-primary/90",
        destructive: "bg-destructive text-destructive-foreground shadow-sm hover:bg-destructive/90",
        outline: "border border-input bg-background shadow-sm hover:bg-accent hover:text-accent-foreground",
        ghost: "hover:bg-accent hover:text-accent-foreground",
      },
      size: {
        sm: "h-8 rounded-md px-3 text-xs",
        default: "h-9 px-4 py-2",
        lg: "h-10 rounded-md px-8",
      },
    },
    defaultVariants: { variant: "default", size: "default" },
  }
)

export interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement>, VariantProps<typeof buttonVariants> {
  asChild?: boolean
}

export const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, asChild = false, ...props }, ref) => {
    const Comp = asChild ? Slot : "button"
    return <Comp className={cn(buttonVariants({ variant, size, className }))} ref={ref} {...props} />
  }
)
Button.displayName = "Button"
```

### B. Base UI (`@base-ui/react` Unstyled + Tailwind)
```tsx
import { Button as BaseButton } from "@base-ui/react/button"

export function Button({ variant = "primary", ...props }: BaseButton.Props & { variant?: "primary" | "secondary" }) {
  return (
    <BaseButton
      {...props}
      className={`inline-flex items-center justify-center rounded-lg px-4 py-2 font-medium transition active:scale-95 focus-visible:ring-2 focus-visible:ring-offset-2 ${
        variant === "primary"
          ? "bg-blue-600 text-white hover:bg-blue-700 focus-visible:ring-blue-500"
          : "bg-zinc-100 text-zinc-900 hover:bg-zinc-200 dark:bg-zinc-800 dark:text-zinc-100"
      }`}
    />
  )
}
```

### C. HeroUI (Tailwind Variants + React Aria)
```tsx
import { Button as HeroUIButton } from "@heroui/react"

export function ActionButton() {
  return (
    <HeroUIButton color="primary" variant="shadow" radius="full" size="md">
      Deploy Project
    </HeroUIButton>
  )
}
```

### D. DaisyUI (Semantic Pure CSS)
```tsx
export function DaisyButton({ variant = "primary" }: { variant?: "primary" | "secondary" | "accent" }) {
  return <button className={`btn btn-${variant} btn-sm md:btn-md`}>Click Me</button>
}
```

## 7. Crucial Rules & Anti-Pattern Defenses

1. **Never Mix Conflicting CSS-in-JS Runtimes**: Do not mix MUI Emotion runtime and Ant Design CSS-in-JS in the same Next.js App Router tree without isolated boundaries; it degrades server render performance.
2. **Always Mark Portals with `"use client"`**: Dialogs, Sheet/Drawers, Tooltips, and Popovers rely on DOM measurement and browser portals. Mark their files with `"use client"` at the very top.
3. **Avoid Hydration Mismatch on Dynamic Themes**: When using DaisyUI (`data-theme`) or dark mode CSS classes, use `next-themes` with `suppressHydrationWarning` on `<html>`.
4. **Prefer Semantic Design Tokens over Arbitrary Hex**:
   - ❌ `<div className="bg-[#1e293b] text-[#f8fafc]">`
   - ✅ `<div className="bg-card text-card-foreground border border-border">`
5. **Enforce WAI-ARIA Keyboard Focus**: Every custom trigger element must handle `Tab`, `Enter`, `Space`, and `Escape`, with visible focus rings (`focus-visible:ring-2`).
